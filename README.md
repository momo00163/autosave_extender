# Stormworks autosave Extender

Stormworks: Build and Rescue の車両セーブのバックアップ世代数（デフォルトの10個）を自動で拡張・保護し、過去のセーブデータを設定した上限まで無制限に蓄積できるようにする。

---

## 同梱されているファイル

- `stormworks_shift_backup.exe` — バックグラウンド監視プログラム
- `config.ini` — 設定ファイル
- `setup.bat` — ワンクリック自動インストーラー
- `uninstall.bat` — 完全アンインストーラー
- `README.txt` — 説明書

---

## 導入方法（インストール手順）

1. リリースページなどからZIPファイルをダウンロードし、お好きなフォルダに**「すべて展開（解凍）」**してください。
   > ※ ZIPファイルを開いた状態のままではインストールに失敗します。必ず解凍してください。

2. **【任意】設定のカスタマイズ**
   * 展開したフォルダ内にある **`config.ini`** をメモ帳などで開き、最大保持数やチェック間隔などを自由に変更して保存してください。（初期状態のままでも問題なく動作します）
   * その後、同じフォルダ内の **`setup.bat`** をダブルクリックして実行します。

### ⚙️ 自動で行われること
* ユーザーの `AppData` 内への専用フォルダ作成と、プログラム・設定ファイルの配置
* Windowsのスタートアップ（自動起動）への登録
* バックグラウンド常駐の即時開始（すぐに監視がスタートします）

これですべてのセットアップは完了です！次回からパソコンを起動すると自動でスタンバイし、Stormworksの起動・終了に合わせて賢く連動します。

---

## 使い方

普段通りにStormworksをプレイしてセーブ（またはオートセーブ）を行うだけで自動的に動作します。

* 通常枠（`autosave0` 〜 `autosave9`）から押し出された古いセーブデータは、自動的に `autosave10`、`autosave11` …へとスライドして安全に保護されます。
* ゲーム内のロード画面から、過去の古いバックアップデータをいつでも選択してロードできるようになります。

---

## 設定の変更方法 (`config.ini`)

ZIP解凍先の **`config.ini`** を編集してから **`setup.bat`** を起動して適用するか、インストール先のファイルを直接編集してください。

```ini
[Settings]
; 保持するバックアップの最大インデックス番号（例: 30の場合、autosave30まで保存）
max_index = 30

; セーブフォルダの変更をチェックする間隔（秒）
check_interval = 30

; Stormworksが起動しているかをチェックする間隔（秒）
process_check_interval = 5
