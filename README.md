========================================================
  Stormworks 無限バックアップ拡張システム
  (Stormworks Infinite Backup Extender)
========================================================

【概要】
このツールは、Stormworksの車両セーブのバックアップ世代数（デフォルトの10個）を
自動で拡張・保護し、過去のセーブデータを設定した上限まで無制限に蓄積できるようにする
バックアップ常駐アシスタントです。

【同梱されているファイル】
・ stormworks_shift_backup.exe  (バックグラウンド監視プログラム)
・ config.ini                   (設定ファイル)
・ setup.bat                    (ワンクリック自動インストーラー)
・ uninstall.bat                (完全アンインストーラー)
・ README.txt                   (この説明書)


--------------------------------------------------------
  ■ 導入方法（インストール手順）
--------------------------------------------------------
1. このZIPファイル内のすべてのファイルを、お好きなフォルダに「すべて展開（解凍）」してください。
   ※ ZIPファイルを開いた状態のままではインストールに失敗します。必ず解凍してください。

2. 【任意】お好みで設定をカスタマイズする
   展開したフォルダ内にある **「config.ini」** をメモ帳などで開き、
   最大保持数やチェック間隔などを自由に変更して保存してください。
   （※初期状態のままでも問題なく動作します）

3. 展開したフォルダ内にある **「setup.bat」** をダブルクリックして実行してください。
   
   【自動で行われること】
   - ユーザーのAppData内への専用フォルダ作成と、プログラム・設定ファイルの配置
   - Windowsのスタートアップ（自動起動）への登録
   - バックグラウンド常駐の即時開始（すぐに監視がスタートします）

これですべてのセットアップは完了です！
次回からパソコンを起動すると自動でスタンバイし、Stormworksの起動・終了に合わせて賢く連動します。


--------------------------------------------------------
  ■ 使い方
--------------------------------------------------------
普段通りにStormworksをプレイしてセーブ（またはオートセーブ）を行うだけで自動的に動作します。

- 通常枠（autosave0 〜 9）から押し出された古いセーブデータは、
  自動的に「autosave10」「autosave11」…へとスライドして安全に保護されます。
- ゲーム内のロード画面から、過去の古いバックアップデータをいつでも選択してロードできるようになります。


--------------------------------------------------------
  ■ 設定の変更方法 (config.ini について)
--------------------------------------------------------
同梱されている **「config.ini」** をメモ帳などで開くことで、動作のカスタマイズが可能です。
**※ zip解凍先のiniを編集し、setupを起動して適用**

【設定項目の詳細】
[Settings]
; max_index = 30
  -> 保持するバックアップの最大インデックス番号です。（例: 30の場合、autosave30まで保存）
  
; check_interval = 30
  -> セーブフォルダの変更をチェックする間隔（秒）です。（デフォルト: 30秒）
  
; process_check_interval = 5
  -> Stormworksが起動しているかをチェックする間隔（秒）です。

※設定ファイルを保存すると、次回のチェックタイミングで自動的に新しい設定が適用されます。
  （プログラムの再起動は不要です）
  
--------------------------------------------------------
  ■ 削除方法（アンインストール）
--------------------------------------------------------
本ツールを完全に削除したい場合は、同梱されている **「uninstall.bat」** をダブルクリックして実行してください。

【自動で行われるクリーンアップ内容】
1. バックグラウンド常駐プロセスの安全な終了
2. Windowsのスタートアップ自動起動登録の削除
3. インストール済みプログラム・設定フォルダの削除
4. **Stormworks内の拡張バックアップデータ（autosave10以降）の自動リセット・一括削除**
   ※ 通常枠（autosave0 〜 autosave9）のセーブデータは削除されず安全に保持されます。

--------------------------------------------------------
  ■ 注意事項
--------------------------------------------------------
- 本ツールはWindows環境（StormworksがインストールされたPC）専用です。
- ゲームのアップデートや仕様変更により動作に影響が出る場合があります。
